# Project Governance — MacroMag

This document defines the organizational structure, decision-making process, and intellectual property guidelines for the **MacroMag** open-source ecosystem (also operating under the **MacroMag Foundation** community banner).

---

## 1. Mission & Core Principles
MacroMag is an open-source hardware-software ecosystem licensed under **GNU GPL v3.0**, dedicated to:
* **Digital Sovereignty:** Zero-telemetry, offline-first computing environments.
* **Open Architecture:** Developing a 64-bit RISC-V microkernel, the Virtualized Object Shell (VOS), and a Rust/C execution runtime.
* **E-Waste Reduction:** Designing modular, repairable hardware architectures utilizing magnetic and pogo-pin interconnects.

---

## 2. Core Maintainer Team (Leadership)
The project is governed by a three-person Core Maintainer Team responsible for technical direction, security, legal compliance, and community operations:

* **Adrian Morawski — CEO & Project Lead**
  * **Responsibilities:** Overall project vision, system architecture, roadmap strategy, and external representation.
* **Alan Morawski — Security, Code & Legal Lead**
  * **Responsibilities:** Code auditing, cybersecurity compliance, licensing enforcement (GNU GPL v3.0), and organizational governance.
* **Marek Damian (Maldyrek) — Operations & Community Admin**
  * **Responsibilities:** Infrastructure administration, operational support, and community coordination.

---

## 3. Decision-Making Process
* **Day-to-Day Development:** Technical decisions, pull request reviews, and issue triaging are handled by the Core Maintainer Team via GitHub discussions and pull requests.
* **Major Governance Changes:** Strategic decisions—including license modifications, adding new Core Maintainers, hardware commercialization, or transitioning into a formal legal entity—require a **unanimous consensus** of the Core Maintainer Team.

---

## 4. Funding & Financial Transparency
* MacroMag operates as a non-profit R&D collective managed transparently through **Open Source Collective**.
* All donations, sponsorships, and grants are strictly allocated to open-source research and development, including 64-bit RISC-V development boards, FPGA testing hardware, modular interconnect prototyping, and domain/server infrastructure.
* Financial records and expense approvals are publicly visible on our [Open Collective page](https://opencollective.com/macroMag)
